Sobre los Datos y la Fuente de Información

Información de la API y Atribución

Los datos que estructuran este catálogo provienen de servicios públicos enfocados en la indexación de contenido multimedia de animación y literatura japonesa.

  • API Utilizada: Jikan API (v4), una API REST no oficial pero abierta y gratuita para MyAnimeList.
  • Mantenimiento: Desarrollada y mantenida por la comunidad de código abierto liderada por Irfan Dahdah y colaboradores en GitHub.
  • Licencia de la API: Licencia MIT (Open Source).
  • Atribución de los Datos: Los datos originales de las obras, sinopsis, puntuaciones y portadas pertenecen a MyAnimeList y a sus respectivos autores, editoriales y estudios de animación. Deben ser atribuidos a MyAnimeList (https://myanimelist.net/).

Peticiones HTTP Realizadas

Para la construcción de este sitio web, se han consultado endpoints específicos de la API mediante peticiones GET:

  • GET https://api.jikan.moe/v4/manga?q=Berserk&limit=1: Consulta de información detallada del manga Berserk.
  • GET https://api.jikan.moe/v4/manga?q=Fullmetal%20Alchemist&limit=1: Petición para obtener los datos de Fullmetal Alchemist.
  • GET https://api.jikan.moe/v4/manga?q=Frieren&limit=1: Recuperación de metadatos de Sousou no Frieren.

Transformación de Datos: Del JSON al HTML

A continuación se muestra un fragmento real devuelto por la API en formato JSON y cómo se ha transformado manualmente a etiquetas semánticas de HTML para mostrar la ficha del elemento.

1. Fragmento real del JSON (Código fuente)

{
  "mal_id": 2,
  "url": "https://myanimelist.net/manga/2/Berserk",
  "title": "Berserk",
  "score": 9.47,
  "scored_by": 375410,
  "rank": 1,
  "status": "Publishing",
  "chapters": null,
  "synopsis": "Guts, a former mercenary now known as the "Black Swordsman", is looking for slaughter..."
}

2. Conversión a HTML estructurado

Este bloque representa cómo se traduce la estructura anterior a lenguaje de marcas para ser renderizada en el navegador:

Berserk

  • Puntuación: 9.47
  • Ranking: #1
  • Estado: Publishing
  • Sinopsis: Guts, a former mercenary now known as the "Black Swordsman", is looking for slaughter...
